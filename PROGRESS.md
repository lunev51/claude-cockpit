## Известные ограничения

- Значки статус-бара Claude Code держатся на вшитом шрифте
  (`assets/fonts/JetBrainsMonoNF-*.woff2`, +2 МБ): на маке Nerd Font не
  установлен, и без бандла там были пустые прямоугольники.
- `Ctrl+Tab` в браузере недоступен — переключение вкладок по номеру.
- `Cmd+W` закроет вкладку с кокпитом, перехватить нельзя.
- Спящий ПК недоступен: Tailscale его не разбудит.
- `Ctrl+V` в терминале перехвачен под вставку, то есть `0x16` (literal-next) с
  клавиатуры больше не отправить. В Claude Code он не используется.
- **Голосовой ввод работает только в окне на ПК.** По сети запись не доезжает:
  `recorder` отдаёт `ArrayBuffer`, а транспорт сериализует кадр через
  `JSON.stringify` — у `ArrayBuffer` нет перечислимых свойств, и на провод
  уходит пустой объект; main видит не WAV и отвечает «неверный формат». То есть
  push-to-talk с макбука не отправлял ни байта, а сообщение про формат уводило
  в сторону.
  Решение владельца (10.08): не чинить — голосом с макбука он не пользуется.
  Чтобы ограничение не выглядело поломкой, в браузере удержание клавиши сразу
  говорит «голосовой ввод работает только в окне кокпита на ПК».
  Если понадобится починить — нужен транспорт для бинаря: base64 в кадре
  (30 с записи ≈ 1,3 МБ, потолок кадра 16 МиБ это переживёт) либо отдельный
  бинарный кадр WebSocket.

## Где вести разработку (правило изменено 10.08)

Работаем **прямо в этом репозитории**. Дубликат
`C:\Users\Lunev\AssistClaude\claude-cockpit-net` больше не основное место
разработки — он синхронизирован с main и лежит про запас.

**Условие одно, но жёсткое: кокпит должен быть ЗАКРЫТ, пока идут правки.** Не
свёрнут крестиком (тот прячет окно в трей, приложение живо), а закрыт пунктом
«Выход» в меню трея. Проверять фактом, а не на слово: `Get-Process electron`
должен быть пуст.

Почему это важно. 10.08 кокпит владельца дважды вылетел прямо во время работы,
и виноваты были правки в живом каталоге:

- мутационные проверки пишут в `src/main/*.js` заведомо сломанный код на
  несколько секунд и возвращают обратно;
- `git stash push -u`, `git checkout` и смена веток подменяют разом весь
  исходник;
- сетевой сервер отдаёт файлы renderer с диска на КАЖДЫЙ запрос, а Electron
  читает модули при старте — то есть живое приложение читает те же файлы,
  которые в этот момент переписываются.

Если понадобится запустить кокпит для живой проверки, не трогая рабочее
состояние (вкладки, манифест), — только с отдельным каталогом данных:

```
npm start -- --user-data-dir=C:\Users\Lunev\AppData\Roaming\cockpit-net-data
npm run smoke -- --user-data-dir=C:\Users\Lunev\AppData\Roaming\cockpit-net-data
```

Пользовательский конфиг в таком каталоге — **`config.user.json`** (не
`config.json`); там же задаётся свой порт, чтобы не драться с рабочим кокпитом.

## Помнить

- Bash на этой машине съедает бэкслэши в путях — команды с путями через PowerShell.
- `Select-Object -First N` в конвейере со `npm run smoke` обрывает поток и роняет
  процесс: код выхода ненулевой при полностью успешном прогоне.
- Ревьюеру с мутациями — изолированная копия дерева (`git worktree` + junction на
  `node_modules`), не рабочее.
- Параллельным агентам — непересекающиеся файлы; `git add` поимённо, не `-A`.
- Двойные кавычки и длинное тире в `git commit -m` ломают разбор командной строки
  PowerShell — сообщение писать файлом и `git commit -F`.
- Windows кэширует недоступный сетевой адрес на минуты: повторный замер того же
  UNC отвечает мгновенно и ничего не доказывает — брать свежий адрес.
- `localhost` считается защищённым контекстом. Проверять поведение браузера на
  маке нужно по СЕТЕВОМУ адресу, иначе Clipboard API доступен и проверка врёт.
