## Как запускать дубликат

**Только с флагом изоляции**, иначе дубликат перезапишет `workspace.json` рабочего
кокпита и его `bridge-port` — хуки живых сессий уйдут не в тот процесс:

```
npm start -- --user-data-dir=C:\Users\Lunev\AppData\Roaming\cockpit-net-data
npm run smoke -- --user-data-dir=C:\Users\Lunev\AppData\Roaming\cockpit-net-data
```

`package.json` для изоляции НЕ менять: переименование утекло бы в основной проект при
слиянии PR.

## Что сделано

Кокпит умеет отдавать свой интерфейс по сети:

- `src/main/command-registry.js` — все 43 команды вызываются по имени, а не только из
  локального окна;
- `src/main/broadcast.js` — единая точка исходящих событий (окно + сетевые клиенты);
- `src/main/output-buffer.js` — хвост вывода каждой вкладки, чтобы подключившийся
  клиент видел, на чём остановилась работа;
- `src/main/net-server.js` — HTTP-статика и WebSocket;
- `src/renderer/js/{api-boot,net-api,api-shape}.js` — тот же `window.api` поверх сокета;
  разметку `index.html` править не пришлось.

## Как включить удалённый доступ

**Намеренно НЕ включено.** Сервер слушает `127.0.0.1`, то есть доступен только с самого
ПК. Чтобы открыть с макбука, в `C:\Users\Lunev\AppData\Roaming\cockpit-net-data\config.user.json`
дописать:

```json
{ "net": { "host": "100.120.245.85", "allowedHosts": ["<имя-машины>.tailXXXX.ts.net"] } }
```

и перезапустить кокпит с флагом изоляции.

**Что это значит.** Аутентификации в этой фазе нет — она отдельным планом. Проверка
источника подключения защищает только от чужой страницы в браузере; любой
не-браузерный клиент (скрипт, curl) из тайлнета подключится и получит доступ к
терминалу и к хвосту вывода всех вкладок. Решение о включении принимает владелец
машины.

## Помнить

- Задачи выполняются ПОСЛЕДОВАТЕЛЬНО, если трогают один файл: в этой ветке уже был
  случай, когда временная строка ревьюера попала в чужой коммит.
- Ревьюер, проверяющий тесты мутациями, обязан работать в изолированной копии дерева,
  а не в рабочем.
- `Ctrl+Tab` в браузере недоступен (разведка): переключение вкладок кокпита — по номеру.
- `Cmd+W` закроет вкладку с кокпитом, перехватить нельзя.
