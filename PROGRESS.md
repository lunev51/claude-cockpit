## Что работает

Кокпит отдаёт свой интерфейс по сети. Браузер на другой машине **подключается** к
живым вкладкам (не создаёт новые), видит историю вывода, печатает в терминал,
видит агентов и слэш-команды.

- `src/main/command-registry.js` — все 43 команды вызываются по имени;
- `src/main/broadcast.js` — единая точка исходящих событий;
- `src/main/output-buffer.js` — хвост вывода вкладки (256 КБ);
- `src/main/net-server.js` — HTTP-статика + WebSocket;
- `src/renderer/js/{api-boot,net-api,api-shape,attach-guards}.js` — браузерная половина.

Попутно починен баг базового продукта: перезапуск мёртвой вкладки поднимал процесс и
тут же от него отрекался — ввод не работал, процесс осиротевал, каждое нажатие плодило
ещё один.

## Известные ограничения (чинятся планом 2)

- **Окно на ПК не сворачивается** при подключении с макбука — передачи управления нет.
- **Размер терминала «плывёт»**: у pty один размер на всех, подключившийся клиент
  присылает свой. Пока эстафеты нет — держать открытым что-то одно.
- Трея и автозапуска нет: закрыл окно перед уходом — подключаться не к чему.
- `Ctrl+Tab` в браузере недоступен (разведка), переключение вкладок — по номеру.
- `Cmd+W` закроет вкладку с кокпитом, перехватить нельзя.

## Помнить

- Bash на этой машине съедает бэкслэши в путях — команды с путями через PowerShell.
  Уже дважды создавало мусорные папки из испорченного пути.
- Ревьюеру, проверяющему тесты мутациями, работать в изолированной копии дерева
  (`git worktree` + junction на `node_modules`), а не в рабочем.
- Параллельным агентам — только непересекающиеся файлы; `git add` поимённо, не `-A`.
  Был случай, когда чужая временная строка утекла в чужой коммит.
- После `git pull` в рабочем кокпите проверять зависимости: план 1 добавил `ws`,
  без установки падали 6 тестов.
