## Как запускать дубликат

**Только с флагом изоляции**, иначе дубликат перезапишет `workspace.json` рабочего
кокпита и его `bridge-port` — хуки живых сессий уйдут не в тот процесс:

```
npm start -- --user-data-dir=C:\Users\Lunev\AppData\Roaming\cockpit-net-data
npm run smoke -- --user-data-dir=C:\Users\Lunev\AppData\Roaming\cockpit-net-data
```

`package.json` для изоляции НЕ менять: переименование утекло бы в основной проект при
слиянии PR.
