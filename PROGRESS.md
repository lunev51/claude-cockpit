  заглушка с кнопкой. Невладелец смотрит, но не пишет. Размер терминала

- **План 3 (PR #27).** Файловый обзор: новая сессия из ЛЮБОЙ папки с любой

Правки по итогам живой приёмки: вставка (#25), размер терминала при возврате
(#26), синхронизация вкладок между клиентами (#28), шрифт для мака (#29),

**Про кнопку ⟳ стоит помнить:** она стоит рядом с `/compact`, а перезапуск
прерывает живую сессию. Подтверждения намеренно нет (просьба была избавиться от
лишних нажатий). Если начнёт задеваться случайно — делать подтверждение только
для случая, когда сессия прямо сейчас работает, а не всегда.

**Что это значит на практике.** Доступ к терминалу открыт всем устройствам

HTTPS (вторая половина плана 4) тоже не делается. Его отсутствие стоило двух
обходных путей, оба уже сделаны и работают:

- **вставка** в браузере отдаётся самому браузеру (`Cmd+V`), потому что
  Clipboard API в незащищённом контексте недоступен;
- **копирование** идёт через устаревший `execCommand` (см. `clipboard.js`).

Если HTTPS когда-нибудь появится — оба обхода можно снять, но сами по себе они
рабочие.

## Известные ограничения

- Значки статус-бара Claude Code держатся на вшитом шрифте
  (`assets/fonts/JetBrainsMonoNF-*.woff2`, +2 МБ): на маке Nerd Font не
  установлен, и без бандла там были пустые прямоугольники.
- `Ctrl+Tab` в браузере недоступен — переключение вкладок по номеру.
- `Cmd+W` закроет вкладку с кокпитом, перехватить нельзя.
- Спящий ПК недоступен: Tailscale его не разбудит.
- `Ctrl+V` в терминале перехвачен под вставку, то есть `0x16` (literal-next) с
  клавиатуры больше не отправить. В Claude Code он не используется.

## Помнить

- Bash на этой машине съедает бэкслэши в путях — команды с путями через PowerShell.
- `Select-Object -First N` в конвейере со `npm run smoke` обрывает поток и роняет
  процесс: код выхода ненулевой при полностью успешном прогоне.
- Ревьюеру с мутациями — изолированная копия дерева (`git worktree` + junction на
  `node_modules`), не рабочее.
- Параллельным агентам — непересекающиеся файлы; `git add` поимённо, не `-A`.
- Двойные кавычки и длинное тире в `git commit -m` ломают разбор командной строки
  PowerShell — сообщение писать файлом и `git commit -F`.
- Windows кэширует недоступный сетевой адрес на минуты: повторный замер того же
  UNC отвечает мгновенно и ничего не доказывает — брать свежий адрес.
- `localhost` считается защищённым контекстом. Проверять поведение браузера на
  маке нужно по СЕТЕВОМУ адресу, иначе Clipboard API доступен и проверка врёт.
