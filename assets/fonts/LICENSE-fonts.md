## JetBrains Mono Nerd Font

`JetBrainsMonoNF-Regular.woff2`, `JetBrainsMonoNF-Bold.woff2` — моноширинный
шрифт терминала и монотекста интерфейса.

Это JetBrains Mono, пропатченный проектом Nerd Fonts: к обычным глифам добавлены
иконки в приватной области Unicode. Ими Claude Code рисует свой статус-бар
(модель, папка, индикатор, стрелки) — без них на машине без этого шрифта вместо
значков видны пустые прямоугольники.

- JetBrains Mono: © 2020 The JetBrains Mono Project Authors,
  SIL Open Font License 1.1 — https://github.com/JetBrains/JetBrainsMono
- Патч Nerd Fonts: © Ryan L McIntyre и участники, MIT —
  https://github.com/ryanoasis/nerd-fonts

Оба файла получены конвертацией в woff2 из установленных в системе
`JetBrainsMonoNerdFont-Regular.ttf` и `JetBrainsMonoNerdFont-Bold.ttf`
(релиз Nerd Fonts). Начертания и глифы не изменялись — только формат контейнера,
что OFL прямо разрешает.

Полные тексты лицензий — по ссылкам выше; обе допускают распространение в
составе приложения, включая коммерческое, при сохранении этого уведомления.
